# Microscopy-Data-Management-System
Это демо-архитектура системы для хранения, каталогизации и обработки изображений микроскопии. Проект включает:  объектное хранилище (MinIO, S3 API);  реляционную базу данных (PostgreSQL);  ETL-пайплайн на Python;  полное описание схемы данных и патентного стиля архитектурного решения.

This is a demo architecture of a system for storing, cataloging, and processing microscopy images. The project includes:object storage (MinIO, S3 API); relational database (PostgreSQL); ETL pipeline in Python; a complete description of the data schema and the patent style of the architectural solution.

------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Data Lake + PostgreSQL + ETL + API для научных микроскопических данных

Microscopy Data Management System — это система управления научными изображениями микроскопии, разработанная для лабораторий, исследовательских институтов и дата-центров биомедицинских изображений.
Платформа сочетает в себе объектное хранилище (MinIO, аналог AWS S3) и реляционную базу данных PostgreSQL, обеспечивая надежное хранение изображений большой ёмкости и структурированных метаданных экспериментов.

Система создана для решения ключевых проблем лабораторий: разрозненных папок, Excel-таблиц, отсутствия версиирования данных и невозможности централизованного поиска снимков.

## Возможности:
- Хранение больших данных

- Объектное S3-хранилище MinIO для изображений с микроскопов.

- Поддержка больших TIFF, PNG, JPG, RAW.

- Удобные пути доступа, единая структура и автоматическое именование.

##  Структурированные научные метаданные
В PostgreSQL хранятся:

- информация о каждой мыши

- генетическая линия
  
- пол и возраст

- принадлежность к эксперименту

- структура, где найден лимфатический сосуд

- уточненные области (менингеальные синусы, кора, таламус и т.д.)

- IHC-метки

- связанный путь к изображению в MinIO

База заменяет хаотичные Excel-файлы и обеспечивает строгую целостность данных.

## ETL-процесс:
ETL-пайплайн выполняет:

- Extract: загрузку файлов с локальной машины/микроскопного ПО

- Transform: переименование, проверку формата, подготовку

- Load: отправку в MinIO + запись записи в PostgreSQL


## Лабораторное использование

Учёные получают доступ к данным через:

- web-интерфейс MinIO (как облачное хранилище)

- REST API

- Jupyter Notebook 

- простые Python-скрипты

## Архитектура системы


 Микроскоп → Рабочая станция → ETL  →  MinIO (изображения)
                                    ↘ PostgreSQL (метаданные)
